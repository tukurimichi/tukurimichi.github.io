動画をコマにする（フレーム抽出）

動画から静止画を等間隔で切り出して、画像にします。無料・広告なし。

AIは、あなたが作った動画の中身を見られません。だから「この動画のここが変」と伝えるのが難しい。この道具は、動画を等間隔で切り出して画像にします。その画像をAIに渡せば、話が通じるようになります。

ファイルはどこにも送信されません。すべてブラウザの中だけで処理されます。広告なし・会員登録も要りません。

よくある質問

動画はどこかに送られますか？
送られません。切り出しはいま開いているブラウザの中だけで行います。サーバーにアップロードする仕組みがありません。

広告は出ますか？お金はかかりますか？
広告は出ません。無料で、会員登録も要りません。

スマホ（iPhone・Android）でも使えますか？
使えます。撮った動画を選んで「切り出す」を押すと、画像を1枚ずつ、またはまとめて保存できます。長い動画や枚数が多いときはパソコンの方が速いです。

何秒ごとに切り出せますか？
「枚数で決める」（2〜30枚）と「間隔で決める」（何秒ごと）が選べます。1本は40MB・60秒までです。

全部のフレーム（全コマ）を出したい
このページは等間隔の切り出し用です。全コマや長い動画は、下の Python 版（ffmpeg を使う）を使ってください。

コマンドで使いたい人へ

同じことをする Python のスクリプトも置いてあります。ffmpeg を使うので、長い動画や大量の書き出しはこちらが速いです。AIエージェントに使わせることもできます。
