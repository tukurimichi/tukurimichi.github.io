Claude Codeで、これを作った

このサイトも、マスコットも、BOOTHのショップも、全部Claude Code(Anthropicが作ったAIコーディングツール)との会話だけで作った。宣伝文句じゃなくて、実際にやってみて感じたことを正直に書いておく。

できたこと

「AIに1万円渡してみた」という企画そのものが、Claude Codeに実際に手を動かしてもらいながら進んだ記録になってる。ドメインの取得、GitHub Pagesでのサイト構築、Midjourneyでのマスコット制作、BOOTHでの出品まで、指示は日本語の会話だけで、コードを書く・ブラウザを操作する・画像を加工するといった作業は全部Claude Code側がやってくれた。ITが素人でも「こういう感じにしたい」と伝えるだけで形になったのは、正直かなり驚いた。

つまずいたこと

もちろん一直線ではなかった。実際に詰まった場面をいくつか挙げる。

  • ブラウザ操作の接続が途中で切れて、作業をやり直すことが何度かあった
  • 画像処理のスクリプトで、日本語のファイルパスが原因の文字化けにハマった
  • GitHubの編集画面で、自動的にタグが閉じる機能とかち合ってコードが壊れることがあった
  • Midjourneyでダウンロードボタンを押しても、ファイルがどこにも保存されていないことがあった
  • Googleアカウントの切り替えが不安定で、違う自分のアカウントの方に作業してしまいそうになったことがあった

どれも致命的ではなく、都度回り道をしながら解決はできた。ただ「完璧に一発で決まる」というよりは「手探りで直しながら進む」場面が多い、というのが実感。

他の人はどう感じているか

実際に使ってる人の生の声。良い声も、そうでない声も、なるべくそのまま並べる。

他のAIサービスとの違い(参考)

この企画の中で、Claude Code以外にも使ったAIサービスがある。あくまでこの企画での使い方の範囲での印象。

  • Midjourney — マスコットのイラスト生成に使用。絵作りの完成度は高いが、文字を正確に描くのは苦手(なので告知画像の文字はCanvaで手動で入れた)
  • ChatGPT / Claude(会話のみ) — 企画の初期のアイデア出しで利用。ただしブラウザ操作やファイル操作までは手を動かしてくれないので、「作業してもらう」段階からはClaude Codeに切り替えた

用途がそもそも違うので単純な優劣ではなく、「絵を作る」ならMidjourney、「実際に手を動かして作る」ならClaude Code、という役割分担だった。
